## 2026-05-26

### Did

- Read backtrader source: `cerebro.py`, `strategy.py`, `broker.py`, `order.py`.
  Captured observations in `journal/phase_3_references.md` (draft). Key areas studied:
  the `_runnext` bar-by-bar loop order (data → broker → strategy), the in-loop analyzer
  pattern, and the order state machine.

- Started skimming vectorbt: `Portfolio.from_signals` default execution semantics,
  indicator factory, tear-sheet metric list. Key finding: `Portfolio.from_signals` fills
  at bar T by default when the signal was computed on bar T's close — the canonical
  lookahead bug, and it is silent.

### Learned

- **backtrader's T/T+1 boundary is implicit, not named.** The safe default (broker
  processes before strategy each bar) means same-bar execution is unavailable without
  explicitly setting `cheat_on_open`. The boundary is real but the code never states it.
  Our engine should name it: `execution="next_open"` as a `Literal` parameter makes the
  invariant visible in the constructor signature rather than emergent from loop order.

- **vectorbt's lookahead problem is not a known pitfall — it is the default.**
  `from_signals` fills at bar T. The fix requires the caller to shift the signal array.
  Nothing in the API prompts this. Our structural guarantee (fill price is T+1 open,
  always) is the decisive argument for building custom.

- **backtrader's in-loop analyzer pattern is extensibility in the wrong place.** Attaching
  analyzers to `Cerebro` gives streaming computation but couples every metric to the engine
  loop. The cleaner design: make `BacktestResult` complete enough that any report is a pure
  function over the artifact with no engine involvement. This becomes D10.

  API without dropping down to `Portfolio.from_orders`.

### Learned

- **vectorbt v1.0.0 compatibility is no longer a blocker.** The Phase 2 retro flagged
  this as the dependency check item for Phase 3 kickoff. Released 2026-04-22; Python 3.12
  supported. The decision not to use vectorbt is on architectural grounds, not
  compatibility.

- **The lookahead-safety spectrum is the clean framing for D1.** backtrader = opt-in
  danger (via `cheat`); vectorbt = opt-out danger (via `.shift()`); custom = structurally
  impossible. A future reader asking "why not vectorbt?" should be sent to ADR 0004, not
  to a commit message.

### Learned

- **Cap × discount, not effective rate, is the right structure for `TaiwanCostModel`.**
  Storing `commission_cap = 0.001425` and `commission_discount = 0.6` separately exposes
  which is law and which is market practice. Promotional rates (e.g. 1.8折 new-account
  offers) are modeled by overriding only the discount — impossible if the two are
  collapsed into a single field.
